# blooky.ts APIドキュメント

## `blooky.ts`の役割

`blooky.ts`は、関数型リアクティブプログラミング（FRP）を実現するための、中核となるプリミティブとオペレータを提供します。このモジュールはプラットフォームに依存せず、リアクティブなデータフローを構築するための基本的な部品のみを含みます。

## 中心となる概念

`blooky`は、**`Stream`**と**`Prop`**という2つの中心的な概念に基づいています。

* **`Stream` - イベントの流れ**:
    未来に発生する一連のイベントを表現するデータ構造です。`Stream`自体は値を持たず、「これから値が流れてくる可能性がある」という**可能性**や**設計図**を定義します。`map`や`filter`といったオペレータを繋げることで、イベントの流れを合成・変換していくための基本単位となります。

* **`Prop` - 確定した状態**:
    `() => A`という形式の、現在の値を返す関数です。`Stream`から`hold`や`accum`といった関数を通じて生成され、ある時点での**確定した状態**を表現します。UIへの値のバインディングなど、リアクティブシステムから値を取り出すための主要な出口（Exit Point）です。

この2つを明確に分離することで、「イベント」と「状態」を区別し、予測可能でクリーンなデータフローを構築することが、このライブラリの基本思想です。

## APIリファレンス

### プリミティブ生成関数

| 関数 | 説明 |
| :--- | :--- |
| **`stream<A>()`** | 値を外部から投入できる、全ての`Stream`の起点となる`DripperStream<A>`を生成します。 |
| **`hold<A>(initialValue)(s: Stream<A>)`** | `Stream<A>`を受け取り、その`Stream`から流れてきた最新の値を保持する`Prop<A>`を生成します。 |
| **`accum<A, S>(reducer, seed)(s: Stream<A>)`** | `Stream<A>`から流れてくる値を`reducer`関数で畳み込み、その結果を保持する`Prop<S>`を生成します。 |

### Streamオペレータ

| 関数 | 説明 |
| :--- | :--- |
| **`map<A, B>(fn: (v: B) => A)(s: Stream<B>)`** | `Stream<B>`を受け取り、値が流れるたびに`fn`を適用して変換し、新しい`MappedStream<A, B>`を返します。 |
| **`filter<A>(predicate: (v: A) => boolean)(s: Stream<A>)`** | `Stream<A>`を受け取り、`predicate`関数を満たす値だけを通過させる新しい`FilterStream<A>`を返します。 |
| **`merge<A>(fn?)(streams: Stream<A>[])`** | 複数の`Stream`を一つに合流させた、新しい`MergedStream<A>`を返します。 |

### Propオペレータ

| 関数 | 説明 |
| :--- | :--- |
| **`remap<A, B>(fn: (v: B) => A)(p: Prop<B>)`** | `Prop<B>`を受け取り、その現在の値に`fn`を適用して変換する、新しい`Prop<A>`を生成します。 |
| **`lift<A>(fn)(props: Prop<any>[])`** | 複数の`Prop`を受け取り、それらの現在の値すべてに`fn`を適用して単一の値を計算する、新しい`Prop<A>`を生成します。 |

---

### 出口（Exit Point）ユーティリティ

| 関数 | 説明 |
| :--- | :--- |
| **`resolve<A>(source: Stream<A> \| Prop<A>)`** | `Stream`からは**次の値**を、`Prop`からは**現在の値**を取得し、それを解決する`Promise<A>`を返します。リアクティブな世界から一度きりの値を取り出すための基本的な出口です。 |
| **`when<A>(predicate)(p: Prop<A>)`** | `Prop<A>`を監視し、その値が`predicate`を初めて満たした瞬間に、その値で解決される`Promise<A>`（`PromisedProp`）を返します。特定の**未来の状態**を待つための高レベルな出口です。 |

### 時間ベースのAPI

| API | 説明 |
| :--- | :--- |
| **`clock`** | `requestAnimationFrame`に同期して現在のタイムスタンプを保持する、公開された`Prop<number>`。全ての時間ベースのリアクティブ処理の基準点となります。 |
| **`moments`** | `clock`を元に、便利な時間ベースの`Stream`を生成するためのファクトリオブジェクトです。<br>• **`.timeout(ms)`**: 指定時間後に一度だけ発火する`Stream`を返します。<br>• **`.interval(ms)`**: 指定した間隔で発火し続ける`Stream`を返します。<br>• **`.framecount(limit?)`**: フレームごとに発火する`Stream`を返します。 |

### 副作用の生成

| 関数 | 説明 |
| :--- | :--- |
| **`drip<A>(value: A)(s: DripperStream<A>)`** | 指定された`Stream`に値を流した場合に、どの`Prop`がどのように更新されるべきか、という**「実行計画書（`Effect`オブジェクト）」**を生成します。この関数は副作用を**実行しません**。実行は`blooky-dom`の`into`や`blooky-effect`の`execute`といった、実行エンジンが担当します。 |
